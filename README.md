# Healthcare-Claims-Denial-Analysis  
## Project Overview  
I designed this project to identify the root causes of claims denials across a dataset of 120,000 healthcare claims, testing whether documentation completeness, provider specialty, payer type, and diagnosis code could predict denial risk. Using a synthesized dataset from Kaggle, I analyzed denial reason codes and denial rates across each of these factors to isolate which ones actually drive denial outcomes.
## Business Problem  
Health insurance denials are a massive issue in our healthcare system and affect providers and patients alike. Hospitals spend billions trying to get denied claims overturned while patients suffer from delayed care or medication. Without knowing the main drivers of claims denials, it is difficult for providers and patients to avoid a claim being denied.  
## Business Questions  
- Which denial code appears more often?
- Which specialties, ICD-10 codes, or payers are associated with higher denials?
- How much revenue is tied to denied claims?
- Is there one main driver of claims denials?
- What could providers do to reduce claims denials?
